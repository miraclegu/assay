# 固定止损（-15% / -20% / -25%）对四条标星策略的实测

**结论：止损在这四条策略上没有可检出的效应 —— 收益、回撤都不显著；
但它带来的换手与胜率损失是确定的。不建议加。**

## 口径

- 实现：`g.stop_loss`（0 = 关），日频判定，持仓相对**加权平均建仓价**
  跌破 `-stop_loss` 即 `order_target_value(code, 0)`。
- 价格两端同为**后复权**（`Position.entry_price` 与 `close_hfq`），
  所以除权除息不会造成假触发，衡量的是含息总收益。
- 判定时点 `g.stop_time` 默认 `14:00`（INTRADAY），注册在 `check_limit_up`
  **之后**（engine 按时间字符串稳定排序，同一时刻按注册序执行）。
- ⚠️ **这是日频止损不是盘中触发**，两个方向都偏离真实：日内穿到 -18%
  又拉回收盘 -12% 的不触发；跳空低开的按当日收盘价成交，实际止损点
  可能远低于名义位。数字应读作「日线级别止损的效果」。
- 每条策略沿用它**自己那次标星运行**的窗口 / 本金 / 成本口径。
  `stop_loss=0` 一档逐项复现标星数字（froec 期末权益 2,674,004、
  969 笔、胜率 62.75% 一字不差）—— 兼作「补丁是 no-op」的回归检查。

## 为什么判为「无效」而不是「-15% 能砍回撤」

### 1) 收益：非单调，且极差落在已知噪声带内
四条线里三条的年化对止损位**非单调**（-15% 与 -25% 常胜 -20%）。
真效应应当随止损收紧单向移动。froec 四档极差 1.65pp、froec_traded 2.79pp
—— 而 froec 线上已经测过的扰动零分布是「随机剔 3~10 只无关票（0.07%~0.22%
宇宙），13 组 salt 极差 **3.00pp**」。**优势小于扰动噪声**，同 froec_traded
那条结论一样的判据。

### 2) 回撤：全周期那 -7pp 基本上是 2024 一次事件

  动到 17.32%，其唯一的大额节省又是 2026 单次（-5.06pp）。

### 4) 成本是确定的

-15% 档相对无止损：

| 策略 | 平仓笔数 | 胜率 |
|---|---|---|
| froec | 969 → 1080 (**+11.5%**) | 62.75% → 61.67% (**-1.08pp**) |
| froec_traded | 971 → 1077 (**+10.9%**) | 62.51% → 60.82% (**-1.69pp**) |
| sgmspeg_v0b | 770 → 914 (**+18.7%**) | 64.16% → 61.27% (**-2.89pp**) |
| 红利指数增强 | 536 → 574 (**+7.1%**) | 63.06% → 59.41% (**-3.65pp**) |

胜率下降是机制上必然的：止损把「本会回本的浮亏」兑现成已实现亏损。
换手上升直接吃佣金 + 印花税 + 滑点。**用确定的成本，买一个只在单次
事件里兑现的保护。**

## 为什么小市值策略上止损特别不占便宜

这三条都是**周频/月频强制调仓 + 短持有期**（froec 平均持有 33.4 天）。
调仓本身已经是一种「离场」机制 —— 跌下去的票下周多半掉出目标池被卖掉，
止损只是把这个动作提前几天，边际信息量很小。止损真正能救的是
「买入后一路阴跌、但因子始终留在池子里」的情形，这在市值排序下不常见
（跌得越多市值越小，反而更容易留在池子里 —— 止损与选股逻辑方向相反）。

## 代码

`g.stop_loss` / `g.stop_time` / `g.stop_ban` 三个参数已加入
`froec.py`、`sgmspeg_v0b.py`、`红利指数增强.py`（`froec_traded.py`
复用 froec 的实现自动跟随），**默认 0 = 关，不改变任何既有结果**。
保留参数是为了将来能复测，不是推荐启用。

`g.stop_ban`（止损后 N 个交易日不买回）本轮**未测** —— 基线效应已经
不显著，再叠一层参数只会增加过拟合面。若将来要测，先要有理由相信
「止损后立刻买回」是本轮无效的原因。
