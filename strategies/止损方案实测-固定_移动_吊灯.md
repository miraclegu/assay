# 三套止损方案对四条标星策略的实测

测了三套：**固定止损**（-15/-20/-25%）、**移动止损**（从持有期最高收盘价
回撤 -15/-20/-25%）、**吊灯止损** Chandelier Exit（`close < HH(22) - k·ATR(22)`，
k=2/3/4/5）。四条标星策略 × 14 档 = 56 组回测。

| 方案 | 判决 | 一句话 |
|---|---|---|
| 固定止损 **窄档** (-15/-20/-25%) | **无效** | 收益、回撤都不显著，还收真保费 |
| 固定止损 **宽档** (-30/-35/-40%) | ✅ **值得带** | 保费≈0，尾部事件赔付 +2.2~6.5pp（12/12 格为正）|
| 移动止损 | **中性偏负** | 12 格里 9 格收益为负；且**越松越接近基线**，不存在最优位 |
| 吊灯止损 | **🔴 确定性有害** | 16/16 格收益为负、14 格显著；夏普 15 低 1 平 0 高 |

**三套都不建议加。** 下面分开说。

---

# 一、固定止损

**结论：没有可检出的效应 —— 收益、回撤都不显著；
但它带来的换手与胜率损失是确定的。不建议加。**

## 口径

- 实现：`g.stop_loss`（0 = 关），日频判定，持仓相对**加权平均建仓价**
  跌破 `-stop_loss` 即 `order_target_value(code, 0)`。
- 价格两端同为**后复权**（`Position.entry_price` 与 `close_hfq`），
  所以除权除息不会造成假触发，衡量的是含息总收益。
- 判定时点 `g.stop_time` 默认 `14:00`（INTRADAY），注册在 `check_limit_up`
  **之后**（engine 按时间字符串稳定排序，同一时刻按注册序执行）。
- ⚠️ **这是日频止损不是盘中触发**，两个方向都偏离真实：日内穿到 -18%
  又拉回收盘 -12% 的不触发；跳空低开的按当日收盘价成交，实际止损点
  可能远低于名义位。数字应读作「日线级别止损的效果」。
- 每条策略沿用它**自己那次标星运行**的窗口 / 本金 / 成本口径。
  `stop_loss=0` 一档逐项复现标星数字（froec 期末权益 2,674,004、
  969 笔、胜率 62.75% 一字不差）—— 兼作「补丁是 no-op」的回归检查。

## 为什么判为「无效」而不是「-15% 能砍回撤」

真效应应当随止损收紧单向移动。froec 四档极差 1.65pp、froec_traded 2.79pp
—— 而 froec 线上已经测过的扰动零分布是「随机剔 3~10 只无关票（0.07%~0.22%
宇宙），13 组 salt 极差 **3.00pp**」。**优势小于扰动噪声**，同 froec_traded

胜率下降是机制上必然的：止损把「本会回本的浮亏」兑现成已实现亏损。
换手上升直接吃佣金 + 印花税 + 滑点。**用确定的成本，买一个只在单次
事件里兑现的保护。**

## 为什么小市值策略上止损特别不占便宜

这三条都是**周频/月频强制调仓 + 短持有期**（froec 平均持有 33.4 天）。
调仓本身已经是一种「离场」机制 —— 跌下去的票下周多半掉出目标池被卖掉，
止损只是把这个动作提前几天，边际信息量很小。止损真正能救的是
「买入后一路阴跌、但因子始终留在池子里」的情形，这在市值排序下不常见
（跌得越多市值越小，反而更容易留在池子里 —— 止损与选股逻辑方向相反）。

`g.stop_loss` / `g.stop_time` / `g.stop_ban` 三个参数已加入
`froec.py`、`sgmspeg_v0b.py`、`红利指数增强.py`（`froec_traded.py`
复用 froec 的实现自动跟随），**默认 0 = 关，不改变任何既有结果**。
保留参数是为了将来能复测，不是推荐启用。

`g.stop_ban`（止损后 N 个交易日不买回）本轮**未测** —— 基线效应已经

「止损后立刻买回」是本轮无效的原因。

这是噪声的典型指纹，和当初否掉 froec_traded「有 edge」用的是同一条判据。

# 三、吊灯止损（Chandelier Exit）🔴

`g.chand_k` / `g.chand_n`：`close < HH(n) - k·ATR(n)` 即清仓，n=22。
ATR 用真实波幅 `TR = max(H-L, |H-PC|, |L-PC|)` 的简单均值。
建仓时用 `context.data.bar_range` 取**入场前 22 根 K 线**喂满窗口
（否则吊灯在建仓后头十几天完全不设防，等于只测了"持有满 22 天的票"）。

| 策略 | 关 | k=2 | k=3 | k=4 | k=5 |
|---|---|---|---|---|---|
| froec | 36.38 / 46.84 / 1.21 | 23.57 / 38.47 / 1.07 | 26.75 / 37.46 / 1.12 | 28.86 / 38.76 / 1.12 | 33.61 / 37.77 / 1.21 |
| froec_traded | 39.50 / 47.10 / 1.28 | 24.32 / 37.81 / 1.10 | 28.89 / 35.55 / 1.19 | 29.93 / 38.88 / 1.16 | 33.72 / 37.81 / 1.22 |
| sgmspeg_v0b | 32.68 / 52.26 / 1.08 | 14.63 / 44.48 / 0.71 | 17.63 / 45.02 / 0.79 | 21.29 / 42.68 / 0.87 | 21.80 / 44.78 / 0.85 |
| 红利 | 20.07 / 17.95 / 1.30 | 5.70 / 11.94 / 0.67 | 10.55 / 19.95 / 1.01 | 13.06 / 19.36 / 1.10 | 14.46 / 19.02 / 1.08 |

**这一套不是"效应不显著"，是"显著有害"** —— 与前两套的判决性质不同。

## 1) 16/16 格收益为负，14 格 |t| > 2.2 显著

逐年配对收益差：froec -13.01 / -9.30 / -7.04 / -2.47pp；
froec_traded -14.85 / -9.88 / -8.70 / -5.47pp；
sgmspeg_v0b -17.84 / -15.10 / -11.34 / -10.29pp；
红利 -14.66 / -9.62 / -7.17 / -5.66pp。
t 最低 -5.15。**没有一格是正的。**

## 2) 它的回撤下降只是"砍仓位"，而且砍得比朴素减仓还差

吊灯离场后现金要闲置到下一次调仓（周频/月频），所以平均仓位崩塌：

| 策略 | 基线仓位 | k=2 | k=3 | k=4 | k=5 |
|---|---|---|---|---|---|
| froec | 95.2% | 49.0% | 63.4% | 76.2% | 85.1% |
| 红利 | 99.4% | 28.3% | 52.7% | 69.1% | 83.9% |

把回撤按仓位折算（`基线回撤 × 本档仓位/基线仓位` = "只是少拿一半"的朴素预期）：

| 策略 | 档 | 实际回撤 | 折算回撤 | 超出 |
|---|---|---|---|---|
| froec | k=2 | 38.47% | 24.11% | **+14.36pp** |
| froec_traded | k=2 | 37.81% | 24.12% | **+13.69pp** |
| sgmspeg_v0b | k=2 | 44.48% | 25.14% | **+19.34pp** |
| 红利 | k=3 | 19.95% | 9.52% | **+10.43pp** |

**13/16 格的实际回撤高于朴素折算** —— 就是说，同样是"少拿仓位"，
吊灯的效果比无脑减半仓**更差**。它没有择时能力，只是在制造摩擦。

## 3) 夏普符号检验：15 低 / 1 平 / 0 高

夏普对仓位缩放近似不变。若吊灯"只是减仓"，夏普该持平。
实际 16 格里 15 格低于基线、1 格持平、**0 格高于**（符号检验 p ≈ 3×10⁻⁵）。
所以它不只降低了仓位，还降低了**单位风险的回报**。

## 4) 直接证据：它在系统性地卖在低点

胜率从 62~63% 崩到 **43.9~54.0%**，平均持有从 33 天掉到 **3.8~18.6 天**，
平仓笔数从 969 涨到 **3538**（k=2，3.7 倍）。
ATR 阈值在小市值股 20%+ 的日波动下几乎天天被触发，
卖出 → 现金闲置 → 下次调仓再原价买回，纯摩擦。

# 为什么这三套在这批策略上都不占便宜

共同原因：**这四条策略本身已经内置了离场机制**。
周频/月频强制调仓 + 短持有期（froec 平均 33.4 天）意味着
"跌下去的票下周多半掉出目标池被卖掉"—— 止损只是把这个动作提前几天，
边际信息量很小，而摩擦成本是全额的。

小市值线还有一层反向作用：**跌得越多市值越小，反而更容易留在池子里**，
止损与选股逻辑方向相反 —— 止损卖掉的正是因子想买的。

而任何一种"卖出后不立刻补仓"的规则，在周频/月频调仓的框架下都会付出
**现金闲置**的代价。吊灯把这一条推到极致（仓位掉到 28~49%），
所以它的伤害最大、也最容易被量出来。

# 代码

`froec.py` / `sgmspeg_v0b.py` / `红利指数增强.py` 三个文件里统一实现
（`froec_traded.py` 复用 froec 自动跟随），六个参数**默认全 0 = 关**：

| 参数 | 默认 | 含义 |
|---|---|---|
| `stop_loss` | 0 | 固定止损，相对建仓价 |
| `trail_stop` | 0 | 移动止损，相对持有期最高收盘价 |
| `chand_k` | 0 | 吊灯止损系数 |
| `chand_n` | 22 | 吊灯窗口 |
| `stop_time` | '14:00' | 判定时点 |
| `stop_ban` | 0 | 止损后 N 个交易日不买回（**未测**） |

三套可同时开，任一触发即清仓。全关时逐项复现标星数字（froec 期末权益
2,674,004 / 969 笔 / 胜率 62.75%，一字不差）。

引擎侧新增：`Bar` 加 `high_hfq` / `low_hfq`（吊灯要真实波幅），
`Feed.bar_range()` + guard 透传（建仓时喂满 ATR 窗口，`end` 同样受
PIT 防火墙约束）。`current()` 里 high/low 与 close 同属收盘派生量，
只在 INTRADAY/CLOSE 相位放出。

**保留这六个参数是为了将来能复测，不是推荐启用。**

# 四、宽档固定止损（-30% / -35% / -40%）✅ —— 修正前面的结论

## 先说前面错在哪

**这个判据对尾部保险天然不适用** —— 保险的价值本就不该体现在均值上；
一个在均值检验里显著的"保险"，多半是买贵了或者在做择时。
第一节回答的是"止损能不能提高收益/降低平均回撤"，
而**"能不能防极端事件"是另一个问题，要用尾部指标来答**。

窄档（-15/-20/-25%）的结论不变 —— 它们收真保费。
但**宽档是另一回事**，下面重测。

**赔付证据只有 n=1** —— 样本内只发生过一次真正的尾部事件（2024-02）。

这与"用回测收益去论证止损有 edge"是两码事 —— 后者需要显著性，前者不需要。

## 顺带修正：这条策略上「个股暴雷」不是真实敞口

froec_traded 基线 971 笔的亏损尾部：

| 亏损档 | 笔数 | 占比 |
|---|---|---|
| ≤ -20% | 30 | 3.09% |
| ≤ -25% | 15 | 1.54% |
| ≤ -30% | 8 | 0.82% |
| ≤ -35% | 3 | 0.31% |
| ≤ -40% | 1 | 0.10% |
| ≤ -60% | **0** | 0.00% |

最惨一笔 **-50.2%**，退市清算 **0 笔**。
周频调仓 + 平均持有 33 天，**根本不给"连续跌停 / 退市"留时间**。
所以止损在这条策略上真正拦到的**不是个股暴雷，是系统性因子崩塌** ——
最惨的 15 笔里有 6 笔在 2024-02-02~02-05 同时破位，是同一次事件。

⚠️ 曾据此推断「A股暴雷路径是停牌→连续一字跌停，止损卖不掉」——
**实测不成立**：这 15 笔里停牌天数 0~1 天、破位后可卖天数 2~71 天，
机制上卖得掉。撤回该说法。

## 推荐

要选一档，**-35%**：

- froec 38.88 / 42.38 / 1.28（基线 36.38 / 46.84 / 1.21）—— 三项全胜
- froec_traded 42.10 / 42.40 / 1.36（基线 39.50 / 47.10 / 1.28）—— 三项全胜

**不要把上面那些"三项全胜"当成 edge 证据** —— froec -30% 与 froec_traded -30%
仍然符号相反（-0.92pp vs +2.87pp），单格收益差依旧在噪声里。
采纳理由是「保费≈0 + 赔付方向一致 12/12」，不是「它更赚钱」。

# 五、盘中触发版 + 逐年独立回测 —— 前面两节的方法论修正

## 5.1 方法论：逐年独立回测

前面所有逐年表都是从**一次全程回测**里切出来的，这有个致命缺陷：
**止损一旦在某年触发，之后的持仓就与基线永久分家**，后续每年的差额里
混着"路径分叉"而不是"止损作用"。实测这个污染有多大：

| 策略 | 止损触发 **0 次**的年份 | 触发 >0 次的年份 |
|---|---|---|
| froec | n=6，平均\|差\| 1.29pp，**最大 4.15pp** | n=5，平均 8.24pp |
| froec_traded | n=6，平均\|差\| 1.92pp，**最大 8.42pp** | n=5，平均 7.65pp |

**止损一整年没开过火，账户收益却能差 8.42 个点** —— 全程回测切出来的
逐年差根本不在测止损。

改成**逐年独立回测**（每年 1/1 建仓、12/31 清算、本金重置）后立刻干净：
没触发的年份差额精确等于 `+0.00pp`。代价是每年年初有一次冷启动，
但两个臂完全相同，配对比较仍成立。

⚠️ **以后测任何"会改变持仓路径"的规则，都要用逐年独立口径。**

## 5.2 触发次数的正确口径

曾用 `reason=='intraday'` 的笔数差当触发次数 —— **错的**，
`intraday` 把炸板离场也算进去了（2022 年出现过 "-1 次"，
实为 -35% 那版恰好少了一只炸板持仓）。
现已给止损单独出口 `order_stop_sell()`，成交记 `reason='stop'`，
并可直接读 `g.n_stop`。

## 5.3 盘中触发 vs 日频（g.stop_intraday）

- **日频（默认）**：14:00 用当日**收盘价**判定与成交。
- **盘中**：`low_hfq <= 建仓价×(1-stop)` 即认为止损单被打掉；
  成交价 = 跳空低开(`open <= 止损价`)取 open，否则取止损价，
  再由 broker **夹进当日真实 [low, high]** —— 策略无法凭空造价。
  一字跌停（`high == low` 且跌停）仍然卖不掉，记拒单。

全周期（各自标星口径，-35%）：

| 策略 | 关 | 日频-35% | 盘中-35% |
|---|---|---|---|
| froec | 36.38 / 46.84 / 1.21 | 38.88 / 42.38 / 1.28 | 39.06 / **38.51** / 1.29 |
| froec_traded | 39.50 / 47.10 / 1.28 | 42.10 / 42.40 / 1.36 | 40.87 / **38.54** / 1.33 |
| sgmspeg_v0b | 32.68 / 52.26 / 1.08 | 32.40 / 46.58 / 1.09 | 32.53 / 46.52 / 1.10 |
| 红利 | 20.07 / 17.95 / 1.30 | 20.06 / 17.95 / 1.30 | 20.13 / 17.95 / 1.30 |

**收益上几乎没差别，回撤上 froec 两条各再降 ~3.9pp。**
触发次数几乎相同（20 vs 21 次 / 10.6 年）——
**不是触发更频繁，是同一批触发时逃得更早、卖得更好。**

## 5.4 🔴 最重要的一条：日频版在 2024 的收益优势是假的

逐年独立口径下，2024 那年（唯一有意义触发的年份，12 次）：

| 策略 | 基线 | 日频-35% | 盘中-35% | 日频收益差 | **盘中收益差** | 回撤 关→日→盘 |
|---|---|---|---|---|---|---|
| froec | +8.59% | +10.71% | +10.76% | +2.12pp | +2.17pp | 45.00→40.11→**38.84** |
| froec_traded | +17.80% | +22.77% | +17.49% | **+4.98pp** | **-0.31pp** | 45.00→40.11→**38.84** |
| sgmspeg_v0b | +15.55% | +13.65% | +19.45% | -1.91pp | +3.90pp | 51.32→45.35→**44.80** |

froec_traded 那 **+4.98pp 在更真实的盘中版里塌成 -0.31pp**
（v0b 则反向，-1.91 → +3.90）。日频"晚一天按收盘价卖"纯属运气，
两个方向都出现过。

**所以真实图景是：止损用大约 0 到一点点收益，换 4~6pp 的回撤。**
这才是保险该有的样子 —— 前面第四节读出的"既省回撤又赚钱"是日频近似的产物。

## 5.5 逐年独立口径下的最终判决

| 策略 | 盘中-35% 收益差均值 | t | 变好年份 | 2024 回撤差 | 判决 |
|---|---|---|---|---|---|
| froec | +0.15pp | +0.52 | 3/11 | **-6.16pp** | ✅ 可带 |
| froec_traded | -0.00pp | -0.04 | 3/11 | **-6.16pp** | ✅ 可带 |
| sgmspeg_v0b | -0.62pp | -0.71 | 1/10 | -6.52pp | ❌ 不带 |
| 红利 | +0.14pp | +0.70 | 2/11 | -0.00pp | ❌ 不带 |

- **froec / froec_traded：带，用盘中版。** 保费真的是 0（-0.00~+0.15pp，
  8/11 年差额精确为 0），赔付是 2024 回撤 -6.16pp。
- **sgmspeg_v0b：不带。** 日频口径下逐年独立 **0/10 年收益变好、
  均值 -0.67pp、t=-2.08 显著为负**；盘中版靠 2024 的 +3.90 把均值拉到
  -0.62pp/t=-0.71，但 2016 -7.23pp、2017 -2.07pp 的代价是实打实的。
  它之前在全程回测里显示"收益持平"，那是路径分叉掩盖了成本。
- **红利：不带。** 8/11 年触发 0 次，2024 回撤差 -0.00pp ——

## 5.6 撤回

  v0b 的保费是 0.5~0.7pp/年且显著。

  含路径污染；逐年独立口径下 froec 两条是 -0.01/-0.02pp。
- 撤回"2024 既省回撤又赚钱" —— 见 5.4。

# 六、组合级止损（g.pf_stop）—— 全周期看很美，逐年独立后崩掉

## 6.1 动机与实现

个股止损防的是**离散风险**；红利这类持仓同向的策略，回撤来自 10~15 只票
一起阴跌，没有单只快到能打掉个股止损（第五节实测：红利各档回撤差全在
-0.33 ~ +0.04pp）。所以直接盯**总权益从峰值的回撤**。

| 参数 | 默认 | 含义 |
|---|---|---|
| `pf_stop` | 0 | 峰值回撤阈值，如 0.15 |
| `pf_wait` | 20 | 触发后至少削仓 N 个交易日 |
| `pf_ma` | 0 | 基准指数需重回 N 日均线上方才恢复（0=不要求）|
| `pf_cut` | 1.0 | 削减比例，1.0=全清 / 0.5=砍一半 |
| `pf_bench` | 各策略基准 | 恢复信号用的指数 |

🔴 **两条必须写对，否则会静默变成"一次性永久空仓"**：

1. **清仓后权益变常数，自身曲线不能再给复位信号** —— 恢复条件只能来自
   外部（冷静期 + 基准均线）。
2. **恢复时必须把峰值重置为当前权益**，否则"回撤仍 ≤ -X"当天就再触发。

## 6.2 全周期网格（看起来很有希望）

红利 48 组 / froec_traded 16 组：

| | 回撤低于基线 | 年化高于基线 | 两项都好 |
|---|---|---|---|
| 红利（基线 20.90/17.95）| **5/48** | 15/48 | 2/48 |
| froec_traded（基线 41.22/47.10）| **16/16** | 4/16 | 4/16 |

froec_traded 看起来极好：回撤 47.10% → 最低 **30.84%**，
且 `pf_stop=0.25` 那四组是收益回撤双改善（43.92% / 37.47%）。

## 6.3 🔴 逐年独立后全崩

|---|---|---|---|---|---|---|---|
| froec_traded | pf15 全清 | **-5.78pp** | -1.63 | 1/11 | **-0.03pp** | 2/11 | 7/11 |
| froec_traded | pf20 砍半 | **-2.92pp** | **-2.29** | **0/11** | -0.49pp | 2/11 | 5/11 |

| 年份 | 收益差 | 回撤差 | 触发 |
|---|---|---|---|
| 2016 | **-12.44pp** | **+2.01pp** | 1 |

典型 whipsaw：-15% 处削仓 → 冷静期 20 天 → 在更高位买回 → 再跌再削，
阶梯式下行把峰谷距离拉得比不设止损还大。

## 6.4 决定性对比：同一次事件（2024），个股止损严格优于组合止损

两者都只在 2024 触发（各 1/11 年），但结果差很远：

| 方案 | 2024 收益差 | 2024 回撤差 | 其余 10 年 |
|---|---|---|---|
| **个股 -35% 盘中** | **-0.31pp** | **-6.16pp** | 8/11 年零触发，均值 -0.00pp |
| 组合 pf25 全清 | **-12.65pp** | -4.87pp | 10/11 年零触发，均值 -1.15pp |

**机制清楚**：组合止损在权益 -25% 处把**全部**仓位砍掉并空仓 20 天，
正好错过 2024-02-06 起的 V 型反弹；个股止损只砍掉**跌破 -35% 的那几只**，
其余仓位留着吃反弹。同一次保护，个股版少赔 12.34pp 收益、多省 1.29pp 回撤。

## 6.5 结论

**组合级止损在这两条策略上都不采用。**

- **红利**：`pf15w40` 11 年只触发 1 次（等于没开），`pf08` 触发 8 年但
  收益 -1.71pp、回撤只 -0.13pp。加上第五节的个股止损全档无效 ——
  **红利 17.95% 的回撤压不动**，它太浅太慢：任何阈值要么够不着、要么全是误报。
- **froec_traded**：回撤能压但代价离谱，且 4 个误报年回撤反而变差。
  真要防 2024 那类尾部，**个股宽档止损（-35% 盘中）严格更优**。

## 6.6 方法论再确认

全周期网格给出 "froec_traded 16/16 回撤全部改善、最多省 16.26pp"，
逐年独立给出 "回撤改善均值 -0.03pp"。**同一份代码、同一份数据，
差别只在测法。** 第五节那条纪律再强调一次：

> **任何会改变持仓路径的规则，必须用逐年独立口径评估。**
> 全周期回测切出来的逐年差里，止损触发 0 次的年份都能差 8.42pp。
