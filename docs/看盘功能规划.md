> 哪些要先补数据源。不查清这个就排期，会做到一半发现没数据。

- **AI 荐股 / 涨停预测** —— 这个项目的纪律是「结论要能自证」，预测类做不到

## 4. 三条贯穿性纪律（改这块之前先读）

1. **单位混着的，必须由服务端给单位表。**
   同一张面板里 `change_pct`/`turnover`/`amplitude` 是**百分数**，
   `roe_ttm`/`rev_yoy` 是**小数**。页面照 `stock.FIELD_UNIT` 渲染，
   不看数值大小猜 —— 猜错 100 倍不报错。

2. **区间涨幅一律后复权。**
   不复权跨除权日有**假跌幅**：601088 近 250 日后复权 +30.9% / 不复权 +24.8%，
   差的就是分红。K 线默认给不复权（对着券商软件看的是它），但页面能切。

3. **指标在服务端算并预热。**
   MA60 要多取 60 根预热再切掉。前端自己算就得多取，而「少取了导致头部
   均线是错的」**不报错**，只是曲线不对。

4. **Canvas 的自证不能只看 DOM 里有没有 `<canvas>`。**
   判据是画布上有**非透明像素**，且切换后像素分布确实变了。
   画崩了（尺寸算错、坐标 NaN）就是一张空白画布，而它不报错。
